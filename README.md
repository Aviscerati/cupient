## Agent readiness

This site includes lightweight agent-readiness files and metadata:

- `https://cupient.tech/robots.txt` with permissive crawl rules, explicit AI bot allow rules, and a sitemap directive
- `https://cupient.tech/sitemap.xml` listing core public URLs
- Discovery links in `/index.html` head for sitemap and agent-friendly alternatives
- `https://cupient.tech/index.md` as a Markdown-readable homepage alternative
- `https://cupient.tech/llms.txt` with agent-oriented site summary and key links
- `https://cupient.tech/agent.json` as minimal protocol/discovery metadata

Structure & Semantics

Document Structure

The HTML Skeleton

Every page starts with <!DOCTYPE html>, followed by <html>, <head>, and <body>.

Semantic Tags

Meaningful Elements

Use <header>, <main>, <article>, <aside>, <footer> for accessible, SEO-friendly markup.

Attributes

id, class & data-*

id is unique, class is reusable. data-* attributes store custom data accessible via JS.

Flexbox

CSS · Flexbox 
.container {
  display:         flex;
  flex-direction:  row;          /* row | column */
  justify-content: space-between; /* main axis */
  align-items:     center;        /* cross axis */
  flex-wrap:       wrap;
  gap:             16px;
}

.child {
  flex: 1;          /* grow + shrink + basis */
  flex-shrink: 0;   /* don't shrink */
  align-self: flex-end;
}

CSS · Vars & Keyframes

  --spacing:  16px;

JavaScript Essentials

Variables & Types

JavaScript 
// const = can't reassign, let = can reassign
const name    = "Alice";           // string
const age     = 30;               // number
const active  = true;             // boolean
const nothing = null;             // intentional empty
let   score   = 0;               // reassignable

// Template literals
const msg = `Hello, ${name}! You are ${age}.`;

// Destructuring
const { x, y } = getPoint();
const [first, ...rest] = [1, 2, 3];

Functions

JavaScript · Functions 
// Function declaration
function greet(name = "World") {
  return `Hello, ${name}!`;
}

// Arrow function (implicit return)
const double = x => x * 2;

// Arrow with body
const add = (a, b) => {
  const result = a + b;
  return result;
};

// Async / await
const fetchData = async (url) => {
  const res  = await fetch(url);
  const data = await res.json();
  return data;
};

DOM Manipulation

JavaScript · DOM 
// Select elements
const el   = document.querySelector("#my-id");
const all  = document.querySelectorAll(".card");

// Read & write
el.textContent = "New text";
el.innerHTML   = "<strong>Bold</strong>";
el.style.color = "red";

// Classes
el.classList.add("active");
el.classList.remove("active");
el.classList.toggle("active");

// Attributes
el.setAttribute("data-value", "42");
const val = el.getAttribute("data-value");

// Events
el.addEventListener("click", (e) => {
  console.log(e.target);
});

Array Methods

JavaScript · Arrays 
const nums = [1, 2, 3, 4, 5];

nums.map(n => n * 2);          // [2, 4, 6, 8, 10]
nums.filter(n => n > 2);       // [3, 4, 5]
nums.reduce((a, b) => a + b);   // 15
nums.find(n => n > 3);          // 4  (first match)
nums.some(n => n > 4);          // true
nums.every(n => n > 0);         // true
nums.includes(3);              // true

// Spread & combine
const more = [...nums, 6, 7];
const copy = [...nums];
